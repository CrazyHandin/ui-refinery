## 主要变化

- 明确全新设计、已有产品扩展、局部修改与纯概念四种流程。始终调用 skill，但局部任务直接实施，避免重复探索与不必要产物。
- 按产品用途选择结构，优先复用文字层级、间距、语义颜色及控件状态等设计变量。增加软件 UI 按需参考。
- 围绕本次操作处理相关加载、空数据、失败、成功、禁用及恢复，并使用代表性真实长度的内容检查布局。
- 细化窄窗口、表格与导航适配、键盘路径、对话框焦点及共享组件回归。
- 截图评审补充同条件对比、问题影响排序、具体复查方法；移除固定审美目标分数和随机种子步骤，保留创意探索与有限轮次精修。
- 新增 skill 效果验证方案，区分结构、流程、视觉、功能与执行成本，明确全局强制调用时如何进行有效对照。
- 同步调用提示和说明；修复测试夹具漏复制新参考文件的问题。归档安装也能记录资源哈希，不将父目录 Git 提交误记为 skill 来源。

| skill-creator 的 quick_validate.py | PASS | 元数据、名称与未完成占位检查 |

| unittest 完整测试 | PASS，25 项 | 原有 23 项检查，加上夹具资源完整性及现有目录不覆盖两项 |
